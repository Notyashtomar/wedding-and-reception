# Shubham weds Sunaina – Wedding Ceremony & Reception

A mobile-first, cinematic digital wedding invitation built with React, Vite and Motion.

- **Wedding** – Saturday, 12 December 2026 at Dreamz Garden, Dwarka (Sehrabandi 4:00 PM · Ghudchadi 4:30 PM · Departure of Barat 6:00 PM)
- **Reception** – Sunday, 13 December 2026, 8:00 PM onwards at SK Precious Banquet, Janakpuri

## Editing the details

All names, dates, programme timings, venues, contact numbers, music and image paths live in `src/weddingConfig.js`.

## Development

```bash
npm install
npm run dev      # local server
npm run build    # production build in dist/
```

## Artwork

Source artwork is in `assets-src/`. After replacing any of it, run `npm run assets` to regenerate the optimised files in `public/images/`. The palace doors on the cover are built from the left half of `doors.jpg`, mirrored for the right leaf.
